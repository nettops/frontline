# Progress

This file used to hold a running, session-by-session narrative log. That
narrative is now fully superseded: `HANDOFF.md` carries the reconciled
current state (read that first), `git log` carries exactly what changed
and when, and `.ai/FINAL_REPORT.md` carries the latest session's full
account. Keeping a second, aging copy of the same history here just gave
a future session more stale prose to read past — see `HANDOFF.md`'s own
standing rule on this, added 2026-09-07.

**What to actually read**, in order: `HANDOFF.md` → `.ai/TASKS.md` (the
current queue) → `git log` for detail on a specific change →
`.ai/FINAL_REPORT.md` for the last full session's narrative, if the short
versions above don't answer the question.

If you're mid-session and need to checkpoint before a context compaction,
write here — but fold it into `HANDOFF.md`/`TASKS.md` and clear this file
back down before the session ends, rather than letting it accumulate.
