Pixel cast — variants on the boss

Nobody here is drawn whole. A character is a spec — build, head, hat, facial hair, clothes, prop, and five colour choices — and the parts are stamped onto one 32×40 grid in order. Every face is the same ten columns wide and every torso opens on the same six, so any moustache fits any head and any collar fits any build. That shared anchor is the only reason a cast of twenty costs less than twenty sprites.

The cast

Twelve, hand-specced. Names are the game's own — LEADER_FIRST_NAMES in config/factionLeaders.ts, which already generates women as bosses, so the cast does too.

Strangers

The same library rolled at random. This is the honest test of a parts system: if the combinations it has never been shown still read as people, the library works. Anything ugly here is a part that needs fixing, not a bad roll.

The library

Every part, on the same neutral man, so the difference is the only thing visible.

Colour is not shape

One spec, five skins and five suits. None of this costs a pixel — the grid holds keys, the character holds hexes.
